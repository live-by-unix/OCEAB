Welcome to OCEAB!
The ultimate mathmatical/data/web computing environment    
To run, you must have:  
Python 3 or higher   
MATPLOTLIB, to install run pip install matplotlib, if that doesn't work use pip3 instead of pip   
Pandas, again to install pip install pandas or use pip3 if it doesn't work     
Numpy, again install with the same instructions and basic troubleshoot
To run oceab_interface.py, you need customtkinter install with pip or pip3 install customtkinter
*** 
A note about pip  
While using the command pip is possible, in good coding practice, pip3 is reccomended to avoid library issues     

***   
Once having all libs installed, cd to the project folder and then do python oceab.py or python3 oceab.py if python fails. For GUI, do everything but with oceab_interface.py
